# The Music Studio (demo)

The free demo of The Music Studio, a JLS Music product: business software for music teachers and studios, on Windows 10 and 11.

The demo opens a made-up practice studio each time. It cannot set up or keep a real studio.

Get it from the JLS Music website: https://www.jlsmusic.co.za/music-studio.html
